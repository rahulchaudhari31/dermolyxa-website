# Image slot — `treatments/`

**What goes here:** One image per treatment, shown on the treatment cards and on
each `/treatments/[slug]` page.

**Recommended size:** `800 × 600` (4:3), JPG/WebP, optimised.

**Files (one per treatment slug):**

| File | Treatment |
| --- | --- |
| `fue-hair-transplant.jpg` | FUE Hair Transplant |
| `prp-therapy.jpg` | PRP Therapy |
| `non-surgical-hair-regrowth.jpg` | Non-Surgical Hair Regrowth |
| `hair-replacement.jpg` | Hair Replacement |
| `skin-rejuvenation.jpg` | Skin Rejuvenation |
| `aesthetic-treatments.jpg` | Aesthetic Treatments |

**Suggested subject:** Close-ups of the treatment, equipment, or a specialist at
work. A dark bottom gradient is applied so white text stays readable.

**Replace:** drop files here and update `src/data/images.ts` → `treatments`.
