# Image slot — `results/`

**What goes here:** Before/after image pairs used in the results slider and the
`/results` gallery.

**Recommended size:** `800 × 800` (1:1), JPG/WebP, optimised. Before and after
images **must be shot from the same angle, lighting and framing** for a
convincing slider.
